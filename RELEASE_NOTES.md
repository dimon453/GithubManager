## GitHub Collaborator Adder — v0.5

Пятая версия с полной поддержкой светлой/тёмной темы, drag-n-drop файлов, проверкой токена, режимом удаления collaborator'ов и историей репозиториев.

### 🎯 Основные улучшения

- **🎨 Две темы оформления** — светлая и тёмная, переключение в один клик
- **📁 Drag-n-drop** — перетащи `.txt` файл прямо в приложение
- **✔️ Проверка токена** — валидация перед запуском операции
- **➕➖ Два режима** — добавление и удаление collaborator'ов
- **📚 История репо** — выпадающий список последних 10 репозиториев
- **🌍 Три языка** — RU / EN / RO с мгновенным переключением

### 📦 Содержимое релиза

- `add_collaborators_gui.exe` — готовый исполняемый файл для Windows (не требует Python)
- `add_collaborators_gui.py` — исходный код GUI версии
- `add_collaborators.py` — исходный код CLI версии
- `requirements.txt` — зависимости для запуска из исходного кода
- `README.md` — подробная документация на русском и румынском
- `CHANGELOG.md` — полный список всех изменений
- `RELEASE_NOTES.md` — этот файл

### 🚀 Быстрый старт

**На Windows (без Python):**
```
1. Скачай add_collaborators_gui.exe
2. Дважды щёлкни по файлу
3. При первом запуске подтверди в Windows Defender (если спросит)
```

**На Linux/macOS или из исходного кода:**
```bash
pip install -r requirements.txt
python add_collaborators_gui.py
```

### ✨ Что нового в этой версии

| Фича | Описание |
|---|---|
| 🎨 Темы | Dark/Light с полной переокраской интерфейса |

| ➕➖ Режимы | Add (добавить) и Delete (удалить) collaborator'ов |
| 📚 История | Сохранение и быстрый выбор последних 10 репо |
| 🌍 Языки | Русский, Английский, Румынский |

### 📋 Требования

- Windows 7+ / macOS 10.10+ / Linux
- Python 3.8+ (для запуска из исходного кода)
- Интернет для работы с GitHub API

- GitHub токен хранится в plaintext в `USERDATA.json` — держи файл в безопасности
- История репозиториев хранится локально и не синхронизируется в облако

## GitHub Collaborator Adder — v0.5

Versiunea cinci cu suport complet pentru teme deschise/întunecate, drag-n-drop fișiere, verificare token, mod ștergere colaboratori și istoricul depozitelor.

### 🎯 Îmbunătățiri principale

- **🎨 Două teme** — deschisă și întunecată, comutare într-un singur clic
- **📁 Drag-n-drop** — trage fișierul `.txt` direct în aplicație
- **✔️ Verificare token** — validare înainte de operație
- **➕➖ Două moduri** — adăugare și ștergere de colaboratori
- **📚 Istoricul repo** — listă derulantă cu ultimele 10 depozite
- **🌍 Trei limbi** — RU / EN / RO cu comutare instantanee

### 📦 Conținutul versiunii

- `add_collaborators_gui.exe` — fișier executabil gata pentru Windows (nu necesită Python)
- `add_collaborators_gui.py` — codul sursă al versiunii GUI
- `add_collaborators.py` — codul sursă al versiunii CLI
- `requirements.txt` — dependențe pentru rularea din codul sursă
- `README.md` — documentație detaliată în limba rusă și română
- `CHANGELOG.md` — lista completă a tuturor modificărilor
- `RELEASE_NOTES.md` — acest fișier

### 🚀 Start rapid

**Pe Windows (fără Python):**
```
1. Descarcă add_collaborators_gui.exe
2. Dublu-clic pe fișier
3. La prima lansare confirmă în Windows Defender (dacă întreabă)
```

**Pe Linux/macOS sau din codul sursă:**
```bash
pip install -r requirements.txt
python add_collaborators_gui.py
```
